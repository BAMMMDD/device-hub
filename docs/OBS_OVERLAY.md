# Device HUB Live：OBS オーバーレイ

- 表示キーを絞ると、空行と行内の空きを詰める。全キー表示では元の物理配列を維持する。
- キーの `FT` はファーストトラベル、`AP` はアクチュエーションポイント (RT では再ON量)、`R` はリセット。単位は mm。通常キーは `AP` / `R`、ラピッドトリガーでは `FT` / `AP` / `R` を表示する。設定値は対象デバイスを検出したときに読み込む。
- ~~マウスの Hz チップ~~ は削除した (Windows 11 が背面プロセスへの raw input 配信を制限するため、配信時に OBS が背面だと信用できない値になっていた)。実測ポーリングはアプリの性能/テスト画面で前面時に確認する。
- 磁気ボタンはバー付き表示で、現在の深さ、トリガー位置（ストロークの %）、RT 感度（無効時 `OFF`）を区別して出す。

`cargo build --locked --release -p devhub-obs` で `target/release/devhub_obs.dll` を作る。既存の OBS に反映するときは、OBS を閉じてインストール済み DLL を差し替え、OBS を起動し直す。ソースの描画サイズが変わるので、必要に応じてシーン上の配置やクロップを調整する。

## 単体利用 (Device HUB アプリ不要・OSS 配布)

プラグインはデバイスを自分で HID 経由で開くので、**Device HUB アプリをインストール・起動していなくても動く**。
アプリが無い環境でも全部の表示設定を OBS のソースプロパティだけで変えられるよう、
プロパティに「**すべての表示設定を OBS で行う**」トグルと「詳細設定」グループがある:

- OFF (既定): 従来通り — アプリの `obs_overlay.json` が効き、OBS プロパティはタイトル/ラベル/アクセント/表示キー選択のみ。
- ON: 下の「詳細設定」が全部有効になり、`obs_overlay.json` を見ない。設定ファイルが無い環境でも既定値で動く。

詳細設定で出る項目: テーマ / マウスの描き方 / 配置 / フィル方向 / 数値・%・バッジ・作動点線・影・押し込み色の各トグル /
描画倍率・キー大きさ・角丸・余白・パネル不透明度・発光のスライダー / カスタムタイトル文字。
アクセント色 (プリセット + カスタムカラーピッカー) と表示キー・ボタンのチェックはモードに関係なく従来のプロパティのまま。

## ロケール (OSS 配布)

プロパティ・ソース名・モジュール説明はすべて OBS のプラグインロケール機構
(`obs_module_get_locale_string`) で引く。`data/locale/` に ini を置くと OBS UI 言語に追従し、
未ロード・キー無し・古い OBS ではコード内の英語フォールバックが出る:

- `data/locale/en-US.ini` — 既定 (全キー必須)
- `data/locale/ja-JP.ini` — 日本語

配布パッケージは `bin/64bit/devhub_obs.dll` + `data/locale/*.ini` を同梱すれば完全に単体で動く。

## カスタマイズ (`%APPDATA%\DeviceHub\obs_overlay.json`)

アプリの「OBS オーバーレイ」ページから編集し、プラグインが約 1 秒ごとに再読み込みする。
新フィールドはすべて `serde(default)` なので古い設定ファイルはそのまま読める。

### デザイン

| キー | 型 | 既定 | 説明 |
|---|---|---|---|
| `theme` | `Glass`/`Light`/`Clear`/`Neon` | `Glass` | 配色プリセット。`Clear` はパネルなし |
| `accent` | `[r,g,b]` | `[60,190,255]` | 枠・タイトル・Hz の色。OBS ソース設定で色を選ぶとそちらが優先 |
| `pressed` | `[r,g,b]` または `null` | `null` | 押し込み色 (フィル・発光・押下輪郭)。`null` = アクセントに追従 |
| `fill_mode` | `Bottom`/`Top`/`Fade` | `Bottom` | 押し込みフィルの方向 |
| `panel_alpha` | 0–100 | `100` | 背景パネルの不透明度 % |
| `glow` | 0–200 | `100` | 押下時の発光強度 % |
| `shadow` | bool | `true` | キーとパネルの落ち影 |
| `scale` | 0.75–3.0 | `1.0` | 描画解像度 |
| `mouse_style` | `Both`/`Shape`/`Bars` | `Both` | マウスの描き方 |

### レイアウト

| キー | 型 | 既定 | 説明 |
|---|---|---|---|
| `key_size` | 0.7–1.4 | `1.0` | キー1個の大きさ係数 (密度) |
| `radius` | 0–2 | `1.0` | 角丸係数。0 で四角 |
| `pad` | 0.5–2 | `1.0` | パネル内側の余白係数 |
| `arrange` | `Side`/`Stack`/`Swap` | `Side` | 「キー + マウス」統合ソースの並び |

### 表示するもの

| キー | 型 | 既定 | 説明 |
|---|---|---|---|
| `title` | bool | `true` | タイトル行 |
| `title_text` | string | `""` | タイトル文字。空 = デバイス名 |
| `labels` | bool | `true` | キー名・ボタン名 |
| `badges` | bool | `true` | キー内の AP/FT/R テキスト |
| `trigger_line` | bool | `true` | 作動点ライン (キー内の横線) |
| `numbers` | bool | `false` | 押し込み量の数字 |
| `num_pct` | bool | `false` | 数字を mm ではなくストローク % で出す |
| ~~`rate`~~ | — | — | (廃止 — 実測 Hz チップ自体を削除) |
| `show_keys`/`show_buttons` | 配列 | `[]` | 表示するキー (`LayoutKey::id`) / ボタン (表示名)。空 = すべて |

### 優先順位

- 「すべての表示設定を OBS で行う」ON のソースはこのファイルを**まったく見ない** — 下の AND ルールは OFF のソースにだけ適用。
- 表示フィルタは **アプリ ∩ OBS プロパティ** の AND (両方に指定があれば積集合)。
- `title`/`labels` はアプリ側と OBS 側の両方 ON のときだけ表示。
- `accent` は OBS 側で明示した色が優先。`pressed` など新しい項目はアプリ側の設定のみ。
- 旧 `hide_keys`/`hide_buttons` は読み取り互換のみ (新規保存では書かない)。
